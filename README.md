# Звонок — школьное расписание

Рабочий прототип интерфейса мобильного приложения и админки. Сейчас проект не зависит от сборщиков и npm: его можно открыть через любой статический сервер.

## Запуск прототипа

```bash
python3 -m http.server 4173
```

После запуска:

- приложение: `http://localhost:4173/`
- админка: `http://localhost:4173/admin.html`

## Сборка Android APK

Проект содержит Capacitor Android-оболочку. Для debug APK:

```bash
npm install
npm run android:debug
```

Готовый файл появится в `android/app/build/outputs/apk/debug/app-debug.apk`.

Для установки на подключённый телефон с включённой USB-отладкой:

```bash
adb install -r android/app/build/outputs/apk/debug/app-debug.apk
```

## Backend и FCM

Backend находится в [backend](/home/sweecks/rosklad/backend). Он отдаёт расписание через API, принимает FCM-токены и запускает планировщик push-уведомлений для уроков и перемен.

```bash
cd backend
npm install
cp .env.example .env
npm run dev
```

Подробная настройка Firebase описана в [backend/README.md](/home/sweecks/rosklad/backend/README.md).

Изменения расписания в демо сохраняются в `localStorage` браузера. Кнопка уведомлений проверяет разрешение браузера и показывает тестовое уведомление.

## Что уже есть

- расписание уроков с временем, кабинетами и преподавателями;
- перемены между уроками;
- выделение текущего и следующего урока;
- недельный переключатель;
- запрос разрешения на push-уведомления;
- адаптивный экран для телефона;
- админка: редактирование строк, добавление урока, сохранение, экспорт CSV;
- настройки уведомлений и публикация общего объявления;
- базовый PWA-кэш для установки на устройство из браузера.

## Текущие данные расписания

- смена: вторая;
- уроки начинаются в 14:00, последний урок заканчивается в 20:15;
- неделя 21—27 сентября 2026 закреплена как неделя с 5 очными уроками;
- следующая неделя автоматически получает 6 очных уроков;
- правило повторяется через неделю;
- все уроки после очного лимита помечаются как `Онлайн`;
- исходный 8-й урок среды отображается с пометкой «время уточняется», потому что в присланной таблице звонков указано 7 временных слотов.

## Как довести до APK/IPA

Для production-версии рекомендуется вынести общую бизнес-логику в React Native + Expo, а данные и push — в backend:

1. Auth: роли `admin`, `teacher`, `student`, `parent`.
2. API: школы, классы, пользователи, уроки, звонки, объявления.
3. База: PostgreSQL/Supabase или Firebase.
4. Push: Firebase Cloud Messaging для Android и APNs через Expo Notifications для iOS.
5. Серверный планировщик: отправляет напоминания за N минут по часовому поясу школы, даже когда приложение закрыто.
6. Сборка: EAS Build для `.apk/.aab` и `.ipa`.

Важно: уведомления из чистого браузерного прототипа работают только как демо. Настоящие push-уведомления при закрытом приложении требуют backend и токены устройств.
